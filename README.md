# Programación Concurrente y Paralela
## Trabajo práctico realizado por Santiago Baldini Cuevas

Dentro de la asignatura **Optativa 1: Programación concurrente y paralela** ubicada en el cuarto año de la carrera Licenciatura en Gestión de las Tecnologías de Información de la Universidad Nacional de José C. Paz 

En este trabajo se implementa y se toma en cuenta la importancia de utilizar procesos computacionales, aplicando diversos paradigmas de la programación para enfocar el problema. Dentro del mismo se aplicaron métodos de **concurrencia y paralelismo** aumentando la eficacia y el potencial de los programas, aprovechando al máximo los recursos del servidor.

Podemos ver ejemplos dentro de la api como al momento de registrar tanto ventas, como usuarios, etc. Donde se utiliza el manejo de hilos con la ayuda de C# y .NET 9. También utilizamos PLINQ para optimizar y procesar de manera paralela grandes volúmenes de datos.

A partir del conocimiento adquirido, me permite ser capaz de desarrollar **soluciones que utilicen adecuadamente la tecnología disponible y hacer un uso eficiente de la misma, con fundamentos teóricos firmes**.

## Tecnologías Utilizadas

- **Backend:**
  - .NET 9
  - PLINQ para procesamiento paralelo de datos
  - System.Threading para manejo de hilos
  - Semáforos para control de concurrencia
  - Servicio de correo electrónico con .NET
  - MySQL como base de datos

- **Frontend:**
  - Angular
  - Bootstrap para el diseño responsivo
